# 🚀 Job Tracker App

> A full-stack web app to track your job applications in one place!
> 
💻 **GitHub:** [PriyaSingh7877/job-tracker](https://github.com/PriyaSingh7877/job-tracker)

---

## ✨ Features
- 🔐 Register & Login (JWT Auth)
- ➕ Add, ✏️ Update, 🗑️ Delete job applications
- 📊 Track status — Applied / Interview / Offered / Rejected
- 📱 Fully Responsive UI

---

## 🛠️ Tech Stack
**Frontend:** React.js, TypeScript, Tailwind CSS, Axios  
**Backend:** Node.js, Express.js, MongoDB, Mongoose  
**Auth:** JWT, bcrypt  
**Deploy:** Vercel (Frontend) + Render (Backend)

---

## 🚀 Run Locally

```bash
# Clone karo
git clone https://github.com/PriyaSingh7877/job-tracker.git

# Backend
cd Backend
npm install
node server.js

# Frontend
cd Frontend
npm install
npm run dev
```
